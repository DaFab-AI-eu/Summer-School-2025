# Summer-School-2025
Material for the participants in 2025 DaFab Summer School


The prerequisiste for a succesful participation in the DaFab Summer school are:
- a Linux laptop with access to Internet and GitHub
- The ability to run Docker containers on the laptop


  From GitHub you will be able to download the following material
  - A DaFab Container packaging the software required for the hands-on
  - Data set for visualization tutorial
  - Code samples for code optimizations
